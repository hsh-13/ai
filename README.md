# AI 학업 플래너 프로토타입

마감이 겹친 주를 미리 보여주고, 내 가용 시간 안에서 현실적인 우선순위를 알려주는 학업 일정 앱.

## 디렉토리 구조

```text
.
├── index.html            # 최신 프로토타입 (GitHub Pages 진입점)
├── CSS/style.css
├── JS/app.js
├── wireframe/            # 10주차 와이어프레임 버전
└── prototyping/          # 프로토타입 변환 버전
```

## 실행 방법
`index.html`을 브라우저에서 열면 됩니다. GitHub Pages: Settings → Pages → Branch `main` / `/ (root)`.

## 현재 기능 (v6)
- 일정 등록·수정·삭제, 진행 상태 변경
- 요일별 가용 시간 입력 (설정)
- 주간 부하 막대 (홈·일정): 마감일부터 거꾸로 가용 시간에 배정하고, 배정하지 못한 시간은 빨간색 `+Nh`로 표시
- 규칙 기반 우선순위 분석 (마감·중요도·소요 시간 + 가용 시간 부족 여부)
- 예시 데이터 넣기/삭제 (예시 일정에는 "예시" 표시)

## 참고
- AI 분석은 아직 Mock(규칙 기반)입니다. 파일 OCR, URL 분석, Gemini API 연동은 미구현입니다.
- 데이터는 브라우저 localStorage에 저장됩니다.

## 버전 기록
| 버전 | 내용 |
|---|---|
| 10주 와이어프레임 v0.1~v0.4 | 흑백 모바일 와이어프레임 (`wireframe/`) |
| 10주 프로토타입 v1 (v5 화면) | 네이비 UI, 일정 CRUD, Mock 분석 (`prototyping/`) |
| 11주 v6 | 요일별 가용 시간, 주간 부하 막대, 예시 데이터, 분석에 가용 시간 부족 반영 |
