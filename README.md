# AI 학업 플래너 프로토타입

## 디렉토리 구조

```text
.
├── index.html
├── CSS/
│   └── style.css
└── JS/
    └── app.js
```

## 실행 방법
`index.html`을 브라우저에서 열면 됩니다. GitHub Pages를 사용하는 경우 저장소의 Settings → Pages에서 배포 브랜치와 루트(`/`)를 선택하세요.

## 참고
- 현재 AI 분석은 화면 동작 확인을 위한 Mock 분석입니다.
- 파일 OCR, URL 실제 페이지 분석, Gemini API 연동은 아직 구현되어 있지 않습니다.
- 일정 데이터는 브라우저의 localStorage에 저장됩니다.
