# AI 학업 플래너 프로토타입

마감이 겹친 주를 미리 보여주고, 내 가용 시간 안에서 현실적인 우선순위를 알려주는 학업 일정 앱.

## 디렉토리 구조

```text
.
├── index.html            # 최신 프로토타입 (GitHub Pages 진입점)
├── CSS/style.css
├── JS/app.js
├── wireframe/            # 10주차 와이어프레임 버전
├── apps-script/Code.gs   # 계정·저장 API + AI 중계 서버 (Apps Script, 실제 배포 전). 설정은 apps-script/SETUP.md
└── prototyping/          # 프로토타입 버전별 단일 파일 (v1, v2, v2.1, v2.2, v2.3, v3.0, v3.1, v3.2, v3.3, v3.4, v3.5, v3.6, v3.7)
```

## 실행 방법
`index.html`을 브라우저에서 열면 됩니다. GitHub Pages: Settings → Pages → Branch `main` / `/ (root)`.


## 현재 기능 (프로토타입 v3.7)
- **일정:** 등록·수정·삭제, 진행 상태, 단계별 진행, 종류 필터, 마감순·우선순위순 정렬, 카드 접기·펼치기. 우선순위는 마감 50%·중요도 30%·소요 시간 20% 규칙 점수
- **가용 시간:** 요일별 기본값, 날짜별 수정(날짜별 값이 우선), 개인 약속은 그날 가용 시간에서 차감
- **주간 부하·계획:** 마감일부터 거꾸로 단계 단위로 가용 시간에 배정, 날짜별 여유·빠듯(가용 시간의 90% 이상)·부족 표시, 부족 시간과 조정 방법
- **오늘 화면:** 오늘 할 일 체크리스트(체크하면 진행에 반영), 앞으로 7일 판단, 코멘트(현재 규칙 기반)
- **공지 붙여넣기 추출:** 3단계(붙여넣기 → 확인 → 단계). 요구사항마다 원문 근거 확인, "확인 필요" 표시, 실패 시 재시도·규칙 기반·직접 입력 선택. 날짜 계산은 코드가 하고 현재는 규칙 기반(Mock)
- **계정·저장:** 닉네임+비밀번호 로컬 계정(앱 시작 화면이 로그인), 계정별 데이터 분리, 브라우저 localStorage 저장. 구글 시트 저장 코드(`apps-script/`)는 있으나 `AI_ENDPOINT`가 비어 있어 미사용
- **공부 타이머:** 홈 캐릭터 카드에서 시작, 1분 = 1 XP, 한 번에 최대 120분 인정, 1분 미만 미기록, 레벨 L→L+1에 60+30×(L−1) XP(숫자는 팀이 임의로 정한 값). 본인이 누르는 방식이라 실제 공부 여부는 확인할 수 없음. 아이템·랜덤 요소는 이후 단계
- **기타:** 예시 데이터 넣기·삭제, 처음 방문 사용법 4장(오늘 화면 ? 버튼으로 다시 보기), 이용 약관·개인정보 안내(수업용 문구, 법적 효력 없음)

버전별 변경 상세는 `CHANGELOG.md`에 있습니다.

## AI 연결 방식
`JS/app.js`의 `AI_ENDPOINT`가 비어 있으면 규칙 기반 Mock으로 동작하고, 화면에 "Mock" 또는 "AI"로 표시된다. 주소를 넣으면 중계 서버로 POST 요청을 보낸다. Gemini API 키는 프론트엔드 코드에 넣지 않고 중계 서버에서만 보관한다. 날짜·시간 계산은 항상 코드가 하고, AI는 추출과 문장 생성만 맡는다. 응답은 코드가 형식을 검증하며, 실패하면 결과를 쓰지 않는다.

| task | 요청 | 응답(JSON) |
|---|---|---|
| extract | `{task, text, today}` | `{title, type, importance, effort(30/60/120/180/300), deadline(null 또는 absolute/relative_week/relative_days + evidence), requirements:[{text, evidence}]}` |
| comment | `{task, today:[{title,hours}], shortages:[{title,shortHours,days}]}` | `{comment}` |

## 참고
- 현재 `AI_ENDPOINT`가 비어 있어 추출·코멘트는 모두 Mock(규칙 기반)입니다. Gemini 연동 코드(`apps-script/Code.gs`)는 초안이며 배포·실제 호출 테스트를 하지 않았습니다. 파일 OCR, URL 분석은 구현하지 않았습니다.
- 데이터는 브라우저 localStorage에 저장됩니다. (v3.3부터 `AI_ENDPOINT`를 연결하면 구글 시트에도 저장하는 코드가 있으나, 현재는 localStorage만 사용합니다.)
