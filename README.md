# AI 학업 플래너 프로토타입

마감이 겹친 주를 미리 보여주고, 내 가용 시간 안에서 현실적인 우선순위를 알려주는 학업 일정 앱.

## 디렉토리 구조

```text
.
├── index.html            # 최신 프로토타입 (GitHub Pages 진입점)
├── CSS/style.css
├── JS/app.js
├── wireframe/            # 10주차 와이어프레임 버전
└── prototyping/          # 프로토타입 버전별 단일 파일 (v1, v2, v2.1, v2.2)
```

## 실행 방법
`index.html`을 브라우저에서 열면 됩니다. GitHub Pages: Settings → Pages → Branch `main` / `/ (root)`.

## 현재 기능 (프로토타입 v2.2)
- 일정 등록·수정·삭제, 진행 상태 변경
- 요일별 가용 시간 입력 (마이 페이지)
- 주간 부하 막대 (홈·일정): 마감일부터 거꾸로 가용 시간에 배정하고, 배정하지 못한 시간은 빨간색 `+Nh`로 표시
- 규칙 기반 우선순위 분석 (마감·중요도·소요 시간 + 가용 시간 부족 여부)
- 예시 데이터 넣기/삭제 (예시 일정에는 "예시" 표시)
- 오늘 할 일 자동 배정: 부하 계산 결과에서 오늘 몫을 보여줌
- 조정이 필요한 일정 안내: 부족한 시간과 하루 추가 확보량을 코드가 계산해 표시
- 특정 날짜만 가용 시간 수정 (일정 화면): 알바·약속 등 불규칙한 날 대응
- 공지 붙여넣기 → 일정 추출: 결과는 입력 폼에 채워지고 사용자가 확인·수정한 뒤 저장
- AI 코멘트: 오늘 할 일과 부족 시간을 문장으로 요약
- 마이 페이지: 아이디·비밀번호 회원가입/로그인/로그아웃/계정 삭제(이 브라우저 안의 로컬 계정이며 서버 인증 아님, 비밀번호는 해시로 저장), 계정별 일정·가용 시간·분석 결과 분리, 이용 약관, 개인정보 취급 안내

## AI 연결 방식
`JS/app.js`의 `AI_ENDPOINT`가 비어 있으면 규칙 기반 Mock으로 동작하고, 화면에 "Mock" 또는 "AI"로 표시된다. 주소를 넣으면 중계 서버로 POST 요청을 보낸다. Gemini API 키는 프론트엔드 코드에 넣지 않고 중계 서버에서만 보관한다.

| task | 요청 | 응답(JSON) |
|---|---|---|
| extract | `{task, text, today}` | `{title, type, date(YYYY-MM-DD), importance, effort(30/60/120/180/300)}` |
| comment | `{task, today:[{title,hours}], shortages:[{title,shortHours,days}]}` | `{comment}` |

응답은 코드가 형식을 검증하고, 실패하면 Mock으로 대체한다. 날짜·시간 계산은 항상 코드가 하고, AI는 추출과 문장 생성만 맡는다.

## 참고
- 현재 `AI_ENDPOINT`가 비어 있어 AI 분석·추출·코멘트는 모두 Mock(규칙 기반)입니다. 파일 OCR, URL 분석, Gemini API 연동은 미구현입니다.
- 데이터는 브라우저 localStorage에 저장됩니다.

## 버전 기록
| 버전 | 내용 |
|---|---|
| 10주 와이어프레임 v0.1~v0.4 | 흑백 모바일 와이어프레임 (`wireframe/`) |
| 프로토타입 v1 (10주차) | 네이비 UI, 일정 CRUD, Mock 분석 (`prototyping/`) |
| 프로토타입 v2 (11주차) | 요일별 가용 시간, 주간 부하 막대, 예시 데이터, 공지 붙여넣기 추출, 오늘 할 일 자동 배정, 조정 안내, 날짜별 가용 시간, AI 코멘트, AI 연결 지점(`AI_ENDPOINT`). 파일: `prototyping/ai_study_planner_prototype_v2.html`, 최신본은 루트 `index.html` |
| 프로토타입 v2.1 (11주차) | 설정 페이지 이름을 마이 페이지로 변경, 데모 로그인·로그아웃, 이용 약관, 개인정보 취급 안내 추가. 파일: `prototyping/ai_study_planner_prototype_v2_1.html`, 최신본은 루트 `index.html` |
| 프로토타입 v2.2 (11주차) | 아이디·비밀번호 로그인(로컬 계정)으로 변경, 회원가입·계정 삭제 추가, 계정별 일정 분리. 파일: `prototyping/ai_study_planner_prototype_v2_2.html`, 최신본은 루트 `index.html` |

변경 내역과 이유는 `CHANGELOG.md`에 기록합니다. 스냅샷 파일은 한 번 만들면 덮어쓰지 않습니다.
