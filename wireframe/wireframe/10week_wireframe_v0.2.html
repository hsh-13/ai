03. 주요 이동 관계

각 화면 안의 버튼을 클릭하면 실제 목적 화면으로 스크롤 이동하며, 도착한 화면에 파란 테두리가 표시됩니다. 메인 하단 메뉴, 일정 등록/상세 이동, 직접 입력·파일·URL 탭 전환, 분석 재실행 안내, 초기화 확인 팝업을 시연할 수 있습니다. Gemini API 호출 및 JSON 저장은 시각화 범위에 포함되지 않습니다.
